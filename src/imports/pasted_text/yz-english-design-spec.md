Keep the existing information architecture, page structure, content order, responsive behaviour, and prototype interactions unchanged.

Upgrade the current low-fidelity Yz English wireframe into a polished high-fidelity product design.

Do not redesign the product structure and do not add new features.

BRAND

Product name:
Yz English

Brand statement:
Real English for Real Life

Product positioning:
A real-life situational English learning platform that helps adult learners prepare for everyday life, overseas living, work, study, and travel.

BRAND PERSONALITY

The design should feel:

* practical
* approachable
* trustworthy
* modern
* warm
* calm
* internationally relevant
* designed for adults
* focused on real life rather than academic study

The platform should not feel like:

* a traditional language school
* a children’s education app
* an exam preparation website
* a corporate training platform
* a highly gamified learning app
* a Canada-only product
* a generic online course marketplace

VISUAL DIRECTION

Create a clean, editorial, mobile-first visual style.

Use:

* generous but efficient spacing
* clear typographic hierarchy
* soft card surfaces
* restrained rounded corners
* subtle borders
* minimal shadows
* clear content grouping
* realistic scenario imagery
* accessible contrast
* simple line icons
* a warm and human visual tone

Avoid:

* excessive gradients
* glassmorphism
* neon colours
* childish illustrations
* flags as primary visual elements
* maple leaves or Canada-themed decoration
* oversized marketing sections
* excessive animation
* overly corporate blue styling
* generic e-learning dashboard patterns

COLOUR SYSTEM

Create an accessible colour system with:

* one distinctive but calm primary brand colour
* one warm secondary accent
* neutral page backgrounds
* readable dark text
* subtle surfaces for learning modules
* separate but harmonious styles for English and Chinese content
* semantic colours for tips, actions, difficulty levels, and applicability tags

Keep the palette internationally relevant and do not make it visually specific to one country.

TYPOGRAPHY

Create a bilingual typography system that works well for both English and Simplified Chinese.

Use:

* a friendly modern sans-serif for English
* a highly readable sans-serif for Chinese
* strong distinction between page title, section title, body text, dialogue, translation, labels, and metadata
* comfortable line height for bilingual reading
* English as the visually primary language
* Chinese as supporting context without making it difficult to find

20. PDF resource cards
21. Related Scenario cards
22. Accordion sections
23. Empty, selected, hover, pressed, and active states

SCENE DETAIL PAGE

Give the Scene Detail page the greatest visual attention.

Use the existing “Returning Clothes at a Store” scenario as the realistic sample content.

Improve the visual presentation without changing the content order.

Requirements:

* Keep the title, introduction, tags, and video clearly visible near the top.
* Make the video feel like the beginning of a learning experience, not an advertisement.
* Present “What Happens in This Scene” as a clear numbered journey.
* Make the dialogue the dominant learning component.
* Clearly distinguish Customer and Staff without using distracting colours.
* In bilingual mode, place Chinese directly below the corresponding English line.
* Keep audio controls compact.
* Make Key Expressions more prominent than Vocabulary.
* Use a distinctive but restrained information style for Culture and Local Tips.
* Make Shadowing Practice feel interactive and actionable.
* Make the PDF resource visible near the end of the learning journey.
* Clearly invite the user to continue to a related scenario.
* Ensure the long page remains easy to scan on mobile.

HOME PAGE

Preserve the existing sections, but improve:

* brand introduction
* featured scenario hierarchy
* category browsing
* travel entry point
* recent scenarios
* resource preview
* visual rhythm between sections

Avoid making the homepage feel like a sales landing page.

EXPLORE PAGE

Improve:

* search visibility
* category navigation
* filter clarity
* scenario card consistency
* information density
* mobile filter behaviour
* distinction between universal and region-specific scenarios

PDF RESOURCES PAGE

Improve:

* distinction between individual scene PDFs and collections
* free and premium resource labels
* category browsing
* resource preview hierarchy
* readability and trust

RESPONSIVE DESIGN

Create polished responsive layouts for:

* mobile: 390 px
* tablet: 768 px
* desktop: 1440 px

Treat mobile as the primary experience.

Do not simply enlarge the mobile page for desktop. Use the additional desktop space carefully while keeping the same information hierarchy.

INTERACTIONS

Preserve all existing prototype interactions.

Add subtle interface feedback only where appropriate:

* button hover and pressed states
* filter selection
* accordion expansion
* segmented control transitions
* card hover states
* mobile navigation active states

Do not add decorative motion or complex animation.

FINAL OUTPUT

Apply the visual system consistently across:

1. Home
2. Explore Scenes
3. Scene Detail
4. PDF Resources

Also create a separate design system reference screen showing:

* colour tokens
* typography hierarchy
* spacing
* buttons
* tags
* cards
* dialogue components
* learning components
* navigation components

Prioritise product usability, bilingual readability, consistency, and future scalability.
